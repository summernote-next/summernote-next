Plugin showcase

Six self-contained plugins live in examples/plugins/. Each plugin ships its own css/ and js/ files, registers itself through summernote.registerPlugin(), and adds a button to the toolbar — without touching any Summernote Next source code. The plugins rely on the existing summernote.summernote.plugins registry and the new summernote.registerPlugin helper that lives in src/js/summernote.js.

Word Counter

Counts words and characters in the status bar and toggles a live badge. Toolbar button: wordCounterToggle.

Alignment Buttons

Four toolbar buttons (alignLeft, alignCenter, alignRight, alignJustify) wrapping the existing editor.justify* methods.

Special Characters

Dropdown picker for currency, math, arrows, Greek letters, and punctuation. Toolbar button: specialCharacters.

Text Styles

Inline <mark>, <code>, <kbd>, <var>, <samp> toolbar buttons.

Link Extractor

Scans the editor for anchors and renders a list of links below the editable area. Toolbar button: linkExtractorToggle.

Emoji Picker

Dropdown picker for smileys, gestures, hearts, and symbols. Toolbar button: emojiPicker.

Welcome to the Summernote Next plugin showcase.
