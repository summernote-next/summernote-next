# Release 1.0.2 – Changelog Summary

This release replaces the legacy icon font with inline SVG rendering, hardens URL handling against XSS, refines the toolbar icon sizing system, and ships expanded automated test coverage. The focus is on security, visual consistency, and a smaller, font-free distribution.

* **Inline SVG Icons**
  All toolbar glyphs are now rendered as inline SVGs from the new `src/font/icons/` manifest.
  The font-based build artifacts (`font/summernote.*`, `src/font/template.scss`, `scripts/build-fonts.js`) and the related CSS imports were removed.
  A new `icons-svg` module loads SVGs on demand with caching, deduplication, and graceful fallbacks, and ships in both the Bootstrap 5 and `summernote-next-classic` bundles.

* **XSS Hardening via `sanitizeUrl`**
  A new `sanitizeUrl` utility was added in `core/func` and applied to user-provided URLs across `AutoLink`, `Editor`, and `LinkDialog`.
  Dangerous schemes (`javascript:`, `data:`, `vbscript:`, `file:`) are now rejected before any DOM insertion.
  Unit coverage was extended to lock in the new URL allow-list behaviour.

* **Icon Base URL Detection**
  Icon base URL detection was modularized to handle edge cases (no `document`, hosts without `getElementsByTagName`, inline bundles) and is now covered by a dedicated spec.
  The detection logic is exported for tests via `__detectIconBaseUrl__` and registered through the new `icons-svg-detection` test module.

* **Toolbar Icon Sizing System**
  New size modifiers (`note-icon-xs`, `note-icon-md`, `note-icon-lg`) standardize the visual hierarchy of toolbar glyphs.
  Square "block" buttons were replaced with natural `btn-sm` sizing and centered SVGs at 100% width.
  Superscript and subscript glyphs were aligned with the toolbar and their baseline adjusted for readability.

* **Dist Build Cleanup**
  Removed `font/` from the published package and deleted the now-unused `build-fonts.js` prebuild script.
  CSS bundles dropped hundreds of lines of `@font-face` declarations and icon class definitions.
  `package.json`, `build-dist.js`, `build-examples-package.js`, and `vite` configs were updated to reflect the fontless pipeline.

* **E2E Test Expansion**
  Added Playwright specs for icon rendering, local-vs-remote asset parity, and toolbar block layout.
  Added a matching Cypress spec for the toolbar block layout to keep both runners in sync.

* **Vite Test Stability**
  Dynamic imports in test files now use `@vite-ignore` to prevent pre-bundling issues with query-string-based module isolation.

* **Comment & Style Cleanup**
  Redundant comments were removed across source files, tests, and styles, and AGENTS.md was updated to discourage future comment noise.
  Formatting was normalized across modules touched by the icon migration.

* **Repository Hygiene**
  Added `screenshots/` and PNG artifacts to `.gitignore` so Cypress and tooling output stay out of version control.

* **Dependency Refresh**
  Project dependencies were updated and the distributable artifacts were rebuilt for the 1.0.2 release.

**Compatibility**: Backward compatible
