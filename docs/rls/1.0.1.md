# Release 1.0.1 – Changelog Summary

This release introduces a Bootstrap-free classic build, overhauls air popover positioning, adds dark mode support, and significantly expands automated test coverage across unit, integration, and end-to-end layers. It improves editor reliability in edge cases without breaking existing integrations.

* **Bootstrap-Free Classic Build**
  A new `summernote-next-classic` bundle ships without any Bootstrap dependency.
  It provides built-in theme presets, independent dialog handling, and a dedicated build script that mirrors every public example page.
  This gives integrators a fully self-contained editor option alongside the standard Bootstrap 5 build.

* **AirPopover Positioning Overhaul**
  The air mode popover positioning logic was refactored to respect editor boundaries and viewport constraints.
  Max-width clamping, editor-bound positioning, and flex-wrap handling ensure the popover stays usable on narrow viewports and complex layouts.

* **Dark Mode Support**
  Configurable dark mode triggers were added with attribute, class, and `data-bs-theme` detection.
  Classic theme presets include matching dark palettes, and the full cycle is covered by dedicated Cypress and Vitest tests.

* **Air Mode Codeview Close Button**
  A floating close button is now rendered for the codeview in air mode.
  This restores a reliable exit path from fullscreen code editing without relying on keyboard shortcuts.

* **Fullscreen Stacking Fixes**
  The `z-index` for fullscreen `.note-editor` styles was adjusted to resolve stacking conflicts with modals and other overlays.
  Modal handling was refined to keep dialogs accessible during fullscreen editing.

* **editableClassName Option**
  A new `editableClassName` initialization option allows custom CSS classes on the editable element.
  This simplifies targeted styling and integration with existing design systems.

* **Expanded E2E Test Coverage**
  Playwright and Cypress test suites were added for fullscreen mode, air mode, toolbar interactions, dialogs, image handling, and theme switching.
  Screenshot generation is integrated to capture visual regressions across supported example pages.

* **Vitest Integration**
  A Vitest configuration was added for unit and integration testing.
  Coverage collection excludes examples and public assets, and script-level tests are wired into the standard `npm test` workflow.

* **Example Package Builder**
  A new build script assembles a runnable examples package with all dist and font assets included.
  The package can be served directly from any static web server without additional setup.

* **Greek Letters & Math Symbols Example**
  A new example page recreates the legacy special characters picker pattern with a custom toolbar button.
  It demonstrates `editor.saveRange`, symbol grid dialogs, and immediate-insert toggling.

* **Style Refinements**
  Button group spacing, hover and focus-visible states, card-body flex handling, and dropdown display behavior were refined for both the Bootstrap 5 and classic builds.
  Redundant alerts and notices were removed from example pages for a cleaner presentation.

* **Dependency Updates**
  Project dependencies were updated and the distributable artifacts were rebuilt for the 1.0.1 release.

**Compatibility**: Backward compatible
